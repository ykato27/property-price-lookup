# 割安マンション検出＋投資判断支援システム

国土交通省「不動産情報ライブラリ」の成約/取引データから理論価格を作り、
募集物件（listing）と比較して「割安候補」を抽出する Streamlit アプリです。

> **本システムの出力は購入推奨ではありません。** 成約データに基づく
> 「精査の優先順位付け」です。理論価格にはモデル誤差（MAPE 約10%前後）があり、
> 割安に見える物件の相当部分は旧耐震・積立不足・借地権などのリスクの裏返しです。
> 購入判断は重要事項調査報告書・長期修繕計画・総会議事録などの一次資料を
> 確認した上で行ってください。

## 仕組み

1. **成約データ基盤**: 不動産情報ライブラリの取引価格・成約価格を
   API（キー申請制）またはダウンロードファイルから取り込み、専用テーブルに蓄積。
2. **理論価格モデル（2層）**:
   - 第1層: 類似成約（同一市区町村×築年帯×面積帯）の中央値/四分位＋時点補正。事例数 n を必ず併記。
   - 第2層: LightGBM の分位点回帰（25%/中央値/75%）で予測区間を出す。
     評価は期間分割（MAPE・区間被覆率）。
3. **割安スコアとゲート**: スコアは理論価格の25%点（保守値）に対する乖離。
   「割安候補」は n≥10・直近2年以内の事例あり・乖離≥15%・区間幅≤1.6・
   ハードフィルタ（旧耐震の近似判定・定期借地権）非抵触をすべて満たすものだけ。
   信頼度（n・区間幅・事例の新しさ）を必ず併記します。
4. **リスクフラグ**: オーナーチェンジ、修繕積立金がガイドライン目安を
   大幅に下回る、小規模棟、listing 陳腐化などを表示。
5. **投資判断レイヤー**: 賃料が入力された物件のみ、表面利回りと NOI 試算
   （仮定をすべて明示）を表示。賃料が無い物件に推定利回りは出しません。
   割安候補は精査チェックリスト（Markdown）つきで出力できます。

listing はポータルサイトのスクレイピングではなく、CSV 投入＋手入力フォームで
取り込みます（取得日・出所が必須）。設計判断の詳細は [docs/DESIGN.md](docs/DESIGN.md)、
データソースと API キー申請手順は [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md)、
評価結果は [docs/EVALUATION.md](docs/EVALUATION.md) を参照してください。

## セットアップ

```bash
uv sync
uv run streamlit run app.py
```

## 使い方

### 1. 成約データを取り込む

API キーがある場合:

```bash
export REINFOLIB_API_KEY="<申請で発行されたキー>"
uv run python scripts/import_transactions.py --api --year 2024 --quarter 1 --area 13
```

ダウンロードしたファイルから取り込む場合（アプリの「データ取込」タブからも可能）:

```bash
uv run python scripts/import_transactions.py --file <JSON/CSVファイル>
```

動作確認だけなら、フィクスチャ（実データではない構造化ダミー）＋サンプル
listing＋モデル学習＋評価までを一括で投入できます:

```bash
uv run python scripts/seed_demo.py
```

### 2. listing を投入する

「データ取込」タブで CSV アップロードまたは手入力フォームから登録します。
CSV は日本語ヘッダ（募集価格・都道府県・市区町村・専有面積・建築年・管理費・
修繕積立金・権利形態・取得日・出所など）に対応しています。**価格は円単位**で
入力してください。

### 3. 理論価格モデルを学習する

「理論価格モデル」タブで学習を実行すると、期間分割の MAPE と区間被覆率が
表示されます（成約データ 200 件以上が必要）。

### 4. 割安候補を確認する

「割安候補」タブで再評価を実行すると、ゲート通過物件が信頼度・リスクフラグ
つきで表示されます。各候補から精査チェックリストをダウンロードできます。

## テスト

```bash
uv run pytest
```

ETL（正規化・重複排除・APIクライアント）、理論価格モデル（類似統計・
分位点回帰・期間分割評価）、割安スコア/ゲート/リスクフラグ、投資試算、
listing 投入、predictions の最新化までを検証しています。

## 注意事項

- 成約データの利用は不動産情報ライブラリの利用規約に従ってください。
- 旧耐震の判定は築年からの近似です（厳密には建築確認日で判定します）。
- 修繕積立金の「目安」は国交省ガイドラインの例示水準との比較であり、
  不足の確定ではありません。
- NOI 試算の空室率・手数料・税額はすべて仮定であり、実績を保証しません。
