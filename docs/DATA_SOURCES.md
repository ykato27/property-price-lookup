# データソース: 国土交通省「不動産情報ライブラリ」

理論価格の土台となる成約/取引データは、国土交通省の
[不動産情報ライブラリ](https://www.reinfolib.mlit.go.jp/)（REINFOLIB）を使う。
ポータルサイト（SUUMO 等）の募集価格ではなく、実際に取引された価格が
理論価格の物差しになるためである。

## API（XIT001）の仕様要約

- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XIT001`
- 認証: リクエストヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（申請制・無償）
- 主なパラメータ:
  - `priceClassification`: `01`=取引価格情報のみ、`02`=成約価格情報のみ、未指定=両方
  - `year`（YYYY）: 取引価格は 2005 年第 3 四半期〜、成約価格は 2021 年第 1 四半期〜
  - `quarter`: 1〜4
  - `area`（都道府県コード）/ `city`（市区町村コード 5 桁）/ `station`（駅コード 6 桁）のいずれか 1 つ以上が必須
- 出力: gzip 圧縮 JSON
- 主な出力項目: Type（中古マンション等）, Region（住宅地/商業地）, MunicipalityCode,
  Prefecture, Municipality, DistrictName, TradePrice, PricePerUnit, FloorPlan, Area,
  UnitPrice, TotalFloorArea, BuildingYear（"1972年" 形式）, Structure, Use, Purpose,
  CityPlanning, CoverageRatio, FloorAreaRatio, Period（"2015年第2四半期" 形式）,
  Renovation, Remarks, PriceCategory

### 注意点

- **XIT001 の出力仕様に最寄駅・駅距離の項目は無い**（2026-10-23 時点の公式
  API マニュアルで確認）。旧「土地総合情報システム」のダウンロード CSV には
  駅情報が含まれていたが、現行 API では駅距離は特徴量として欠損扱いになる。
  本システムの第 2 層モデルは駅距離が欠損でも動くよう設計している。
- 成約価格情報（priceClassification=02）は 2021 年第 1 四半期以降のみ。
- 価格には「取引価格」（アンケート調査ベース）と「成約価格」（レインズ由来）の
  2 系統があり、本システムでは両方を取り込み `source` 列で区別する。

## APIキーの申請手順

1. https://www.reinfolib.mlit.go.jp/api/request/ にアクセスする
2. 利用者種別で「個人」を選択する（個人利用の場合）。利用規約に同意し、
   反社会的勢力に該当しないことを確認して利用申請フォームを送信する。
   申請には氏名・メールアドレス・利用目的などの登録が必要
3. 審査・承認後に API キーがメールで発行される。
   - 審査は申請後 **5営業日が目安**（2026-10-23 時点の申請ページ記載）
   - 受付完了メールは現在送付停止中のため届かない。
     承認メールが **迷惑メールフォルダ** に入る場合があるので要確認
4. 発行されたキーを環境変数に設定する（API利用規約第8条により、
   キーは第三者に公開してはならないため、リポジトリには絶対にコミットしない）:

```bash
export REINFOLIB_API_KEY="<発行されたキー>"
```

5. 取得して取り込む:

```bash
uv run python scripts/import_transactions.py --api --year 2024 --quarter 1 --area 13
```

API を使わず、公式サイトからダウンロードしたファイル（JSON / CSV）を
取り込むこともできる:

```bash
uv run python scripts/import_transactions.py --file <ダウンロードしたファイル>
```

なお、Web 画面の利用（ダウンロードを含む）に API 申請は不要。

## API 利用規約の要点（2026-10-23 に原文を確認）

- **無償**: API の利用も提供情報の利用も無償（API利用規約第1条(3)）
- **クレジット表示が必須**: API を使ったサービスを公開する場合、
  エンドユーザが参照できる場所に以下を表示する（API利用規約第7条）:
  > 「このサービスは、国土交通省の不動産情報ライブラリのAPI機能を
  > 使用していますが、提供情報の最新性、正確性、完全性等が
  > 保証されたものではありません」
- **出典記載**: コンテンツ利用時は「出典：国土交通省 不動産情報ライブラリ」
  を記載する（公共データ利用規約 PDL1.0）
- **キーの管理**: APIキーは発行を受けた本人の責任で管理し、第三者に
  公開してはならない（API利用規約第8条(2)）。漏洩・亡失・不正利用の
  疑いがある場合はお問い合わせフォームから速やかに連絡する
- **3年不使用で停止の可能性**: APIキーを使ったアクセス実績が3年無い場合、
  利用停止されることがある（API利用規約第5条(5)）
- データは参考情報であり、不動産取引の重要事項説明等に用いることを
  保証するものではない（利用規約第3条(4)）— 本システムを「精査の
  優先順位付け」に留める設計方針と整合する
- 出典: https://www.reinfolib.mlit.go.jp/help/termsOfUse/ （2026-10-23 確認）

## 到達性検証（2026-10-23、本開発環境から実施）

| 対象 | 結果 |
| --- | --- |
| `https://www.reinfolib.mlit.go.jp/` | HTTP 200（到達可能） |
| XIT001 エンドポイント（キーなし） | HTTP 401 "Access denied due to missing subscription key"（エンドポイント自体は実在し、キーが必須であることを確認） |
| 旧 `www.land.mlit.go.jp`（土地総合情報システム） | 接続不可（サービス移行済み） |
| 環境変数 `REINFOLIB_API_KEY` | 未設定（この環境にはキーが無い） |

**結論**: エンドポイントには到達できるが、実データの取得には利用申請で
発行される API キーが必須であり、本環境にはキーが無いため、実データの
取り込みは未実施。代わりに、API クライアントとファイルインポータを実装し、
XIT001 の出力形式に合わせたフィクスチャ（構造化ダミー）で ETL・モデル・
スコア計算の全経路を検証した。フィクスチャは実データではない
（`src/market/fixture_data.py` の docstring にも明記）。

キーが用意できれば、上記 CLI で実データを投入するだけで同じ経路が
そのまま実データで動く。

## listing（募集物件）のデータについて

募集価格・賃料・管理費などの listing 情報には個人向けの公式 API が存在しない。
ポータルサイトのスクレイピングは利用規約・robots・負荷の観点で中核に置かない
設計とし（docs/DESIGN.md）、listing は利用者が手元で入手した情報を
CSV 投入または手入力フォームで登録する。取得日と出所は必須項目としており、
取得日から 90 日を超えた listing には陳腐化フラグが付く。
