# 設計判断

本システムは「割安マンション検出＋投資判断支援」であり、出力は
**購入推奨ではなく、精査の優先順位付け**である。設計判断の根拠は
調査レポート（割安マンション投資の先行事例調査、2026-10-23）に基づく。

## なぜスクレイピングを中核に置かないか

- ポータルサイト（SUUMO 等）に個人向けの公式 listing API は存在しない。
  スクレイピングは利用規約・robots.txt・運用負荷の観点で不安定であり、
  セレクタの推測に依存する実装は壊れやすい（旧実装がまさにそうだった）。
- そもそも理論価格の物差しは募集価格ではなく**成約/取引価格**である。
  募集価格同士の比較では「市場より安い」ことの検証にならない。
- よって、成約データは国交省「不動産情報ライブラリ」（公式・申請制 API +
  ダウンロード）に一本化し、listing は利用者が手元で入手した情報を
  CSV / 手入力で投入する方式にした。取得日と出所を必須にしたのは、
  listing の陳腐化（成約済み・価格改定済み）を追跡するため。

## 理論価格モデルはなぜ2層か

- 第1層（類似成約の中央値/四分位）は解釈可能で、事例数 n と最新時期を
  そのまま信頼度の根拠として提示できる。一方、条件を細かくすると
  プールが痩せて n が不足する。
- 第2層（LightGBM 分位点回帰）は特徴量を横断して補完できるが、
  単独では「なぜその価格か」を説明しにくく、外挿に弱い。
- 両者を事例数 n に応じた重み（w = n / (n+20)）でブレンドし、
  片方しか無い場合も動くようにした。

## 割安の定義とゲート

- 学術的な実測では、東京の中古マンション価格モデルの誤差は MAPE 約 9%
  （明治大学の研究）。つまり 10% 程度の乖離はモデルの誤差範囲であり、
  「割安」と呼ぶには不十分である。
- そこでスコアは**中央値ではなく 25%点（保守値）に対する乖離**とし、
  閾値を 15% に置いた。さらに、類似成約 n≥10、直近 2 年以内の事例、
  予測区間幅（75%点/25%点）≤1.6、ハードフィルタ非抵触をすべて満たす
  場合にのみ「割安候補」と表示する。満たさない物件も評価自体は表示し、
  落ちた理由（gate_reasons）を併記する。

## ハードフィルタとリスクフラグ

割安の相当部分はリスクの裏返しであるため、以下を分離して扱う。

- ハードフィルタ（候補から除外）:
  - 旧耐震の可能性: 建築年が 1980 年以前。**築年からの近似判定**であり、
    厳密には 1981 年 6 月 1 日の建築確認日で判定すべきもの。1981 年築は
    「境界年」として警告フラグに留める。UI・チェックリストの文面でも
    近似であることを明示する。
  - 借地権（定期借地権を含む）: 期間満了で資産価値が消えるため、
    通常の所有権物件と同列に比較しない。
- 警告フラグ（候補には残すが必ず表示）:
  - 賃貸中（オーナーチェンジ）: 内見不可、現賃料の持続性リスク。
  - 修繕積立金不足: ㎡単価換算で国交省ガイドラインの目安
    （平均約 335 円/㎡・月）を大幅に下回る（150 円未満）場合。
    あくまで目安との比較であり、不足の確定ではない。
  - 総戸数 30 戸以下: 修繕負担の集中リスク。
  - listing 陳腐化: 取得日から 90 日超。

## 時点補正について（簡易指数の限界）

第1層の時点補正は、蓄積した成約データ自身から作る簡易指数
（都道府県×四半期の㎡単価中央値の比）を使う。国土交通省の不動産価格指数
（既存住宅・マンション）の代替として手元データだけで完結させるための
割り切りであり、以下の限界がある。

- 四半期ごとの中央値は構成変化（どの地区・築年帯が多かったか）に影響される。
- 件数が少ない四半期はノイズが大きい（最小件数を設け、無ければ隣接期間で代用）。
- 本格運用では公表指数への差し替えが望ましい。

## 投資判断レイヤー

- 利回りは**賃料が入力されている物件のみ**計算する。市区町村単位の粗い
  公的賃料統計から個別物件の利回りを推定すると誤解を招くため、
  賃料が無い物件には利回りを一切表示しない。
- NOI 試算の仮定（空室率 5%、賃貸管理手数料は賃料の 5%、固定資産税・
  都市計画税は価格の 0.4%/年の概算、購入諸経費 7%）はすべて
  `InvestmentAssumptions` に集約し、UI に明示する。実績値ではない。
- 割安スコア（価格の物差し）と利回り（収益の物差し）は別軸として分離表示し、
  混同させない。

## 評価方法

- 価格モデルの評価は**期間分割**（古い期間で学習し、新しい期間で検証）に
  統一した。ランダム分割は、同じ地区の将来の成約が学習側に混入して
  精度を過大に見せるため、時系列データの評価として不適切である。
- 指標は MAPE と 50% 予測区間の被覆率（理想 50%）。被覆率が大きく
  下回れば区間が過信気味であることを意味し、ゲートの区間幅条件と
  あわせて解釈する。
- 2026-10-23 時点の実測はフィクスチャ（構造化ダミー）での値であり、
  実データでの性能ではない。docs/EVALUATION.md に分離して記録する。

## predictions の運用

- 評価は物件ごとに「最新のみ有効」（is_latest）。再評価時は旧評価を
  無効化してから新しい評価を保存するため、割安一覧が重複しない。
- listing の property_id は内容ハッシュで決定的に生成し、同じ listing の
  再投入で二重登録にならないようにした。
