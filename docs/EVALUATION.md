# 期間分割評価レポート

価格モデル（第2層: LightGBM 分位点回帰、log(㎡単価)）の評価結果。
評価方法は期間分割（古い期間で学習 → 直近 4 四半期で検証）。

## 2026-10-23 実施分（フィクスチャでの検証）

> **注意: 実データでの評価ではない。** 不動産情報ライブラリの API キーが
> 本環境に無いため、XIT001 形式のフィクスチャ（構造化ダミー、東京 23 区・
> 2021Q1〜2025Q4、対数正規ノイズ σ=0.13）で ETL・モデル・スコア計算の
> 全経路を検証した。以下の数値は「パイプラインが正しく動くこと」の確認であり、
> 実市場でのモデル性能を示すものではない。

| 指標 | 値 |
| --- | --- |
| データ件数 | 1,600 件（学習 1,311 / 検証 289） |
| MAPE | 12.0 % |
| 50% 予測区間の被覆率 | 37.7 %（理想値 50%） |
| 区間幅（75%点/25%点の平均） | 1.18 |

所見:

- MAPE 12.0% はフィクスチャのノイズ水準（σ=0.13）から妥当な範囲。
  実データの先行研究では MAPE 約 9% が報告されており、本システムの
  割安ゲート（保守値基準で乖離 15% 以上）はこの誤差水準を踏まえた設定。
- 被覆率 37.7% は理想の 50% を下回り、予測区間がやや狭い（過信気味）ことを
  示す。実データ投入後は、区間の較正（例: 検証期間での被覆率に基づく
  区間拡大）を検討する。ゲート条件に区間幅の上限（≤1.6）を入れているのは、
  区間が広すぎる＝不確実な物件を候補から外すため。
