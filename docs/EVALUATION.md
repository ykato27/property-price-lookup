# 期間分割評価レポート

価格モデル（第2層: LightGBM 分位点回帰、log(㎡単価)）の評価結果。
評価方法は期間分割（古い期間で学習 → 直近 4 四半期で検証）。

## 2026-10-23 実施分（フィクスチャでの検証）

> **注意: 実データでの評価ではない。** 不動産情報ライブラリの API キーが
> 本環境に無いため、XIT001 形式のフィクスチャ（構造化ダミー、東京 23 区・
> 2021Q1〜2025Q4、対数正規ノイズ σ=0.13）で ETL・モデル・スコア計算の
> 全経路を検証した。以下の数値は「パイプラインが正しく動くこと」の確認であり、
> 実市場でのモデル性能を示すものではない。

| 指標 | 値 |
| --- | --- |
| データ件数 | 1,600 件（学習 1,311 / 検証 289） |
| MAPE | 12.0 % |
| 50% 予測区間の被覆率 | 37.7 %（理想値 50%） |
| 区間幅（75%点/25%点の平均） | 1.18 |

所見:

- MAPE 12.0% はフィクスチャのノイズ水準（σ=0.13）から妥当な範囲。
  実データの先行研究では MAPE 約 9% が報告されており、本システムの
  割安ゲート（保守値基準で乖離 15% 以上）はこの誤差水準を踏まえた設定。
- 被覆率 37.7% は理想の 50% を下回り、予測区間がやや狭い（過信気味）ことを
  示す。実データ投入後は、区間の較正（例: 検証期間での被覆率に基づく
  区間拡大）を検討する。ゲート条件に区間幅の上限（≤1.6）を入れているのは、
  区間が広すぎる＝不確実な物件を候補から外すため。

## 2026-10-23 実施分（実データ・小規模）

APIキーなし経路が見つかったため、実データでも評価を実施した。

- 取得経路: 不動産情報ライブラリの Web 検索画面（会員登録・APIキー不要）
  から CSV をダウンロード → `scripts/import_transactions.py --file` で取り込み。
- データ: 東京都港区・中古マンション等・不動産取引価格情報、
  2025Q1〜2026Q1 の 754 件（重複 1 件を除き 753 件を登録）。
- 評価条件: 期間分割（学習 2025Q1〜Q3 の 515 件 → 検証 2025Q4〜2026Q1 の
  238 件）。単一区・5 四半期のみの小規模評価である点に注意。

| 指標 | 値 |
| --- | --- |
| MAPE | 29.5 % |
| 50% 予測区間の被覆率 | 30.7 %（理想値 50%） |
| 区間幅（75%点/25%点の平均） | 1.25 |

所見:

- MAPE 29.5% は先行研究（東京・大規模データで約 9%）より大幅に大きい。
  学習 515 件では港区のような価格分散の大きい市場（マンション名・棟の
  ブランドで単価が大きく変わるが、その情報は公開データに無い）を
  捉えきれない、という実態を示す数値と解釈する。
- 被覆率 30.7% はフィクスチャ評価（37.7%）よりさらに低く、実データでも
  予測区間は過信気味。区間の較正は引き続き課題。
- 含意: 現状のデータ規模では、割安ゲート（乖離 15% 以上）はモデルの誤差に
  対して十分な余裕とは言えない。実運用では (1) 対象エリアを広げて学習件数を
  数千件規模にすること、(2) 第1層（類似成約の実績値）を主とし第2層を
  補助に回すこと、(3) 候補表示の際は常に事例数と区間幅を併記すること、が
  前提になる。本評価はその根拠となる実測である。

## 2026-10-23 実施分（実データ・本実験: 粒度×手法の検証）

データ規模を拡大し、「どの粒度・どの方法が効くか」を固定プロトコルで
全構成比較した（実験ハーネス: `src/market/experiments.py`、結果の全表は
`experiments/granularity_results.md`）。

- データ: 不動産情報ライブラリ Web 検索画面の CSV ダウンロード（キーなし）
  で取得した実データ 82,575 件（東京都 74,281 ＋ 神奈川県 8,294、
  2021Q1〜2026Q1、中古マンション等・不動産取引価格情報）。
- プロトコル（全構成共通・固定）: 学習 ≤2024Q4（全域 59,026 件）→
  検証 2025Q1〜2026Q1。検証行は対象区の行のみ（港区 753 件 / 世田谷区 824 件）。
  指標は取引総額ベース MAPE と 50% 区間被覆率。
- リーク防止: TE・パラメータ選択・ブレンド重み・区間較正はすべて
  学習期間内データ（時系列 OOF）だけで決定。

| all / te / GBM | 24.54% | 37.32% | 42.63% |
| all / te_extra / GBM | 24.38% | 37.32% | 40.64% |
| all / base / GBM+調整 | 24.79% | 31.47% | 39.18% |
| all / te_extra / GBM+調整 | 23.21% | 33.33% | 41.43% |
| ward / base / GBM | 23.66% | 33.33% | 50.20% |
| ward / te_extra / GBM | 22.61% | 31.21% | 48.87% |
| all / base / 第1層のみ（city） | 30.88% | 31.08% | - |
| all / base / GBM（目的変数=総額） | 27.06% | 32.40% | 36.25% |

| --- | ---: | ---: | ---: |
| all / base / GBM（旧本番構成） | 20.74% | 43.08% | 48.91% |
| all / te / GBM | 18.99% | 40.90% | 46.97% |
| all / te_extra / GBM | 17.01% | 39.20% | 46.84% |
| all / base / GBM+調整 | 19.52% | 37.74% | 44.42% |
| all / te_extra / GBM+調整 | 16.23% | 34.95% | 44.90% |
| ward / base / GBM | 18.92% | 36.04% | 49.39% |
| ward / te_extra / GBM | 16.63% | 31.92% | 49.76% |
| all / base / 第1層のみ（city） | 25.33% | 39.32% | - |
| all / base / GBM（目的変数=総額） | 20.59% | 43.08% | 50.49% |

### 判定と本番反映

採用構成: **scope=all / 特徴量=te_extra / GBM（調整済みパラメータ）/
目的変数=log(㎡単価) / 区間較正あり** を本番 `PriceModel` に反映した。

- te_extra（地区名・駅名 TE ＋建ぺい率・容積率・改装・用途等）は両区・
  両スコープで一貫して MAPE を改善した（all: 港区 −1.80pt、世田谷 −3.73pt）。
- パラメータ調整は te_extra と重ねても有効だった（港区 24.38→23.21、
  世田谷 17.01→16.23）。選択パラメータは両区で同一
  （n_estimators=400, lr=0.06, num_leaves=63, min_child_samples=10）。
- GBM×第1層のブレンドは両区とも重み 1.0（=GBM 単独）が選ばれ寄与なし。
  第2層内ブレンドは採用しない（scoring 側の事例数ベースのブレンドは
  説明可能性のために維持）。
- スコープは ward が港区では最良（22.61%）だったが、世田谷区では
  all/te_extra+調整（16.23%）が ward/te_extra（16.63%）を上回り、
  「ward が常に勝つ」わけではなかった。本番は単一モデルで全自治体を
  扱う設計であり、事例の薄い自治体では ward 単独モデルが成立しないため
  all を採用した。ward 採用は将来の検討事項として残す。
- 区間較正（δ=0.0279、学習期間内 OOF 由来）は被覆率を全構成で改善したが、
  採用構成でも 41〜45% と理想の 50% には届かない。区間は依然やや過信気味。
- 本番反映後の検証: 固定プロトコルで本番 `PriceModel` を学習し直し、
  実験の採用構成と完全一致を確認した（δ=0.0279、港区 MAPE 23.21% /
  被覆率 41.43%、世田谷区 MAPE 16.23% / 被覆率 44.90%、区間幅も一致）。

### 旧評価（29.5%）との比較について

- 旧値 29.5% は「港区のみ 753 件・学習が 2025 年内 515 件・検証が直近
  2 四半期 238 件・㎡単価ベース MAPE」という別プロトコルの参考値であり、
  本実験の数字と直接は比較できない。
- 同一プロトコル・同一検証行での比較では、旧本番構成（all/base）26.18%
  → 採用構成 23.21%（港区、−2.97pt）、世田谷区では 20.74% → 16.23%
  （−4.51pt）が実測の改善幅である。

### 残る限界

- MAPE 16〜23% は先行研究の約 9% には遠い。公開データに所在階・
  マンション名が無いことが天井になっている（港区のように棟ブランドで
  単価が割れる市場では特に効く）。
- 一般性の確認は東京 2 区のみ。神奈川県は学習データとしてのみ使用し、
  検証対象にはしていない。全国データは取得中で、取り込み後に他地域でも
  同じ実験を回す必要がある。
- listing 行には地区名・駅名・建ぺい率等が無いため、te_extra の改善の
  一部は listing のスコアリングには転移しない（欠損として扱われ、
  TE は全体平均にフォールバックする）。転移するのは主に全体の当てはまり
  の改善分である。
- 間取りタイプ（layout_type）は全角表記のため現状ほぼ定数で不活性。
  実験も同一実装で測っているため数字はこの前提で正しいが、半角正規化は
  未検証の改善余地として残る。

## 2026-10-23 実施分（実データ・全国検証: 採用構成は東京以外で通用するか）

全国データの取り込みが完了したため、東京本実験で決めた採用構成
（scope=all / te_extra / 調整済み GBM / log(㎡単価) / 区間較正）が
東京以外でも通用するかを、同一の固定プロトコルで検証した
（結果の全表は `experiments/granularity_results.md` の各実行セクション）。

- データ: 不動産情報ライブラリ Web 検索画面の CSV（キーなし）で取得した
  実データ 269,202 件（47 都道府県・541 市区町村、2021Q1〜2026Q1）。
- プロトコル（東京本実験と完全同一・固定）: 学習 ≤2024Q4（全域 211,324 件）
  → 検証 2025Q1〜2026Q1。検証行は対象地域の行のみ。
  フォールバックは不使用（protocol=fixed）。
- 対象地域の選定: 政令指定都市は `municipality` が区単位で登録されるため、
  当初目安の大阪市・福岡市・横浜市・名古屋市から、検証件数の多い中心区を
  選んだ。大阪市中央区（検証 770 件・同区の学習 2,457 件）、
  福岡市中央区（654 件・2,445 件）、横浜市港北区（475 件・1,752 件）、
  名古屋市中区（399 件・1,267 件）。検証件数はいずれも東京本実験
  （港区 753 件・世田谷区 824 件）と同規模。
- 比較構成: 旧構成（all / base / 既定 GBM）、採用構成
  （all / te_extra / 調整済み＋区間較正）、参考として対象地域単独
  スコープ×採用構成（ward / te_extra / 調整済み＋区間較正）。
  TE・パラメータ選択・区間較正はすべて学習期間内データだけで決定（リーク防止は本実験と同一）。

| 地域（検証 n） | 旧構成 MAPE | 採用構成 MAPE | 差 | 旧構成 較正後被覆率 | 採用構成 較正後被覆率 | 区単独×採用構成 MAPE |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 大阪市中央区（770） | 20.42% | 17.15% | −3.27pt | 35.58% | 43.38% | 17.30% |
| 福岡市中央区（654） | 26.38% | 23.67% | −2.71pt | 36.09% | 45.57% | 22.84% |
| 横浜市港北区（475） | 24.02% | 17.28% | −6.74pt | 46.74% | 48.21% | 16.80% |
| 名古屋市中区（399） | 21.28% | 20.15% | −1.13pt | 45.61% | 52.13% | 19.02% |

較正後区間幅も採用構成が全地域で旧構成より狭い（大阪 1.323→1.286、
福岡 1.494→1.416、横浜 1.572→1.396、名古屋 1.379→1.338）。

### 判定

- **採用構成は東京以外でも通用する。** 4 地域すべてで旧構成より MAPE が
  低く、較正後被覆率・区間幅も全地域で改善した。東京本実験の
  「残る限界」に挙げた一般性（東京 2 区のみ）は、政令市中心区 4 地域まで
  広げて確認できたことになる。
- 全域プール（211,324 件）での学習期間内チューニングが選んだパラメータは、
  4 回の実行すべてで本番採用値（n_estimators=400, lr=0.06, num_leaves=63,
  min_child_samples=10）と一致した。東京＋神奈川のみのプール（59,026 件）で
  選ばれた値が、3.6 倍の全国プールでも再現された。
- **地域差は残る。** 採用構成 MAPE は 17.15〜23.67% と地域で開きがある。
  福岡市中央区は旧・採用とも最も悪く、名古屋市中区は改善幅が最小
  （−1.13pt）で、te_extra の効きには地域差がある。
- **スコープは現行（all）を維持する。** 区単独×採用構成は福岡（−0.83pt）・
  横浜（−0.48pt）・名古屋（−1.13pt）で全域を上回り、大阪では全域が
  僅差で優位（0.15pt）。東京本実験（港区は ward 優位・世田谷は all 優位）
  と合わせても勝敗は地域で入れ替わり、差は最大でも 1.13pt と小さい。
  「学習件数が十分な自治体では ward がやや有利」という傾向はあるものの、
  検証は各地域 1 期間のみで切替基準も未定義であり、地域別スコープ切替を
  本番へ入れる根拠としては弱い。提案に留め、コードは変更しない。
  将来、複数の検証期間で再現が確認できれば「学習件数が閾値以上の
  自治体のみ ward モデルを併用」を検討する。
- **較正の地域差にも注意。** 較正後被覆率は 43.38〜52.13% で、
  大阪市中央区は 43.38% と依然過信気味である。較正係数 δ は全域プール
  共通の OOF 由来であり地域別較正ではない。地域別較正も候補だが、
  根拠は現状この 1 地域の示唆のみで弱いため、同じく提案に留める。
- **未検証の範囲。** 対象は検証件数の多い政令市中心区のみ。事例の薄い
  自治体・非政令市では未検証であり、そこでは all スコープと TE の
  全体平均フォールバックが前提になる。
